# 🩺 Dr. Abdulrahman Hajjar — Urology Surgery Portfolio

Professional multi-page portfolio website for **Dr. Abdulrahman Hajjar**, a 4th-year Urology Surgery resident at the University of Aleppo.

**🔗 Live:** https://eng-hasan-hajjar.github.io/dr-abdulrahman-hajjar-urology/

Built with plain HTML / CSS / JS — no frameworks, fully responsive, Arabic-first (RTL) design.

---

## نبذة عن المشروع

موقع تعريفي احترافي متعدد الصفحات للدكتور **عبد الرحمن حجار**، طالب اختصاص في الجراحة البولية (السنة الرابعة) في جامعة حلب. يقدّم الموقع نبذة عن مسيرته العلمية وقيمه المهنية، مجالات تخصصه في الجراحة البولية، معرضًا لأبرز فئات أعماله وإنجازاته، إجابات عن الأسئلة الشائعة، ووسائل التواصل معه.

## الصفحات

| الصفحة | المحتوى |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `about.html` | نبذة عني، القيم والرؤية، المسيرة العلمية |

| `faq.html` | الأسئلة الشائعة |
| `contact.html` | تواصل معي |

## المزايا التقنية

- تصميم بصري مخصص بالكامل، بهوية لونية خاصة بتخصص الجراحة البولية (كحلي + أزرق صفيري + ذهبي)
- HTML / CSS / JS خام دون أي إطار عمل خارجي
- دعم كامل للغة العربية واتجاه الكتابة من اليمين لليسار (RTL)
- تصميم متجاوب بالكامل على الجوال والتابلت وسطح المكتب
- حركات وانتقالات احترافية: Scroll Reveal، Parallax، Tilt Cards، عداد أرقام، انتقال ناعم بين الصفحات
- يحترم إعداد "تقليل الحركة" (`prefers-reduced-motion`) في متصفح الزائر
- بنية جاهزة لإضافة صور حقيقية لاحقًا في معرض الأعمال (راجع `images/README.txt`)

## التشغيل محليًا

افتح `index.html` مباشرة في أي متصفح، أو شغّله عبر أي خادم محلي بسيط (مثل إضافة Live Server في VS Code) لتفعيل كل السلوكيات بشكل طبيعي.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى الفرع `main` في المستودع.
2. من إعدادات المستودع: **Settings → Pages** واختر `main` (root) كمصدر النشر.
3. سيصبح الموقع متاحًا على الرابط أعلاه خلال دقائق.
